# Assignment 2 - Advanced CSS

## Student

Iskander Shaimerdinov SE - 2524

## Description

This project was created for Assignment 2 on Advanced CSS.

The main goal of the assignment is to practice modern CSS layout techniques using Flexbox and CSS Grid.

The project contains several separate pages that demonstrate different layout techniques and responsive design.

## Tasks

### Task 0 - Navigation Bar

A navigation bar created using Flexbox.

It contains:

- Logo
- Navigation links
- Horizontal alignment
- Spacing between links
- Vertical centering

### Task 1 - Card Row

A row of three cards created using Flexbox.

Each card contains:

- Image
- Title
- Description
- Button
- Hover effect

### Task 2 - Grid Layout

A webpage layout created using CSS Grid.

The layout contains:

- Header
- Sidebar
- Main content
- Footer

CSS Grid Areas are used to organize the sections.

### Task 3 - Image Gallery

A responsive image gallery created using CSS Grid.

The gallery contains nine images with:

- Equal-width columns
- Gaps between images
- Hover effects
- Caption overlays

### Task 4 - Portfolio Page

A portfolio page that combines Flexbox and CSS Grid.

The page contains:

- Navigation bar using Flexbox
- Main layout using CSS Grid
- Project cards
- Sidebar
- Footer

## Technologies Used

- HTML5
- CSS3
- Flexbox
- CSS Grid
- Responsive Design
